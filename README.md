# X / 推特（MaiBot 插件）

让你的 MaiBot 用**她自己的 X（推特）账号**刷帖子：刷她关注的人的时间线、搜帖子、看某个人的帖子、看一条帖子下面的回复（帖子里的图一起看），给喜欢的点赞、收藏，关注喜欢的账号。时间线刷到什么，取决于她自己关注了谁。看到喜欢的图可以收藏进 MaiBot 的表情包；看到的梗和说法可以配合「大肥鱼的日子」插件的 `learn_jargon` / `learn_expression` 记进 MaiBot 的黑话库和表达方式。

**只看不发**：不发帖、不回复、不转发、不私信。

走的是 **X 官方接口**（API v2，按量付费），不模拟网页、不用 Cookie，不违反 X 的规则，号不会因为这个被封。

## 要花多少钱

X 的接口按读到的条数收费（2026 年的公开价格：读一条帖子约 0.005 美元，读一个账号约 0.01 美元，同一天重复读到的只收一次）。插件有**每月花费上限（默认 10 美元，可在 WebUI 调）**：

- 每次请求前先按最贵的情况算进去，剩下的钱不够就不请求，所以不会超支；
- 请求发出去却没拿到结果时按最贵的算（宁可少刷）；
- `/x_status` 能看到这个月大约花了多少。这是按公开价格估算的，**实际扣费以 X 开发者后台为准**，建议在后台也设一个同样的消费上限。

价格变了可以在 WebUI「花费」分组里改。

## 怎么接上

1. 给她注册一个 X 账号（不要用你自己的）。
2. 打开 [X 开发者后台](https://console.x.com)，用任意账号开通开发者、买一点额度（Credits），新建一个应用（App）：
   - 「User authentication settings」里打开 **OAuth 2.0**，应用类型选 **Native App**（公开客户端，不需要 Secret）；
   - 权限选 **Read and write**；
   - **Callback URI** 填 `http://127.0.0.1:56130/callback`，Website 随便填一个你的网址。
3. 把应用的 **OAuth 2.0 Client ID** 填进 MaiBot WebUI → 插件配置 →「X 开发者应用」。
4. 在和她的私聊里发 `/x_login`，插件发来一个授权链接。**用登录着她 X 账号的手机**打开，点「授权」。
5. 页面会跳到一个打不开的网址（`127.0.0.1` 开头），这是正常的。把地址栏里那个网址整个复制，发 `/x_auth 网址`。插件回复「授权好了」就行。

授权信息只存在插件的数据目录里（只有插件能读），不出现在 WebUI 里，也不给模型看。授权会自动续期，一般不用再做。

## 出问题时

- **X 说太频繁**：冷却到 X 给的时间，之后自动恢复。
- **授权失效、X 拒绝访问、开发者额度用完**：暂停所有请求，重启也不会自己恢复。看 `/x_status` 里的原因，处理好后发 `/x_resume`（授权失效的话重新 `/x_login` 就会自动解除）。
- **X 不让她点赞收藏关注**（返回 403）：只停这些操作，刷帖照常，`/x_resume` 后再试。

## 设置

| 分组 | 设置 | 默认 | 说明 |
|---|---|---|---|
| X 开发者应用 | Client ID / Client Secret / 回调地址 | 空 / 空 / `http://127.0.0.1:56130/callback` | Secret 只有机密客户端才填 |
| 花费 | 每月花费上限 | 10 美元 | 每月 1 号重新算 |
| 花费 | 读一条帖子 / 读一个账号 / 一次操作 | 0.005 / 0.010 / 0.015 美元 | X 改价时照后台改 |
| 她的账号 | 点赞 / 收藏 / 关注 | 都开 | 关掉的她就做不了 |
| 她的账号 | 每天请求上限 | 150 | |
| 她的账号 | 每天点赞 / 收藏 / 关注上限 | 20 / 10 / 3 | 同一条不重复做，操作之间至少隔 20 秒 |
| 刷 X | 每次几条 | 10 | 搜索和看回复 X 规定最少 10 条 |
| 刷 X | 每次几张图 | 3 | 0 就不看图 |
| 刷 X | 时间线里显示回复 | 关 | |
| 刷 X | 屏蔽关键词 / 屏蔽账号 | 空 | 照样计费，只是不给她看 |

## AI 能用的工具

| 工具 | 作用 |
|---|---|
| `x_browse` | 刷时间线（可以接着往下刷）、搜索最近 7 天的帖子、看某人的帖子、看一条帖子 |
| `x_replies` | 看一条帖子下面的回复（最近 7 天） |
| `x_action` | 点赞、收藏、关注（帖子的作者或 @用户名） |
| `x_save_emoji` | 把看到的图收藏成 MaiBot 的表情包 |

工具只在私聊里出现。

## 管理命令

| 命令 | 作用 |
|---|---|
| `/x_login` | 开始授权她的 X 账号 |
| `/x_auth 网址` | 把授权后跳转的网址发回来 |
| `/x_status` | 查看账号、这个月的花费、今天的次数、暂停原因 |
| `/x_resume` | 暂停后确认没问题了恢复 |

命令和回复都不存进聊天记录。

## 开发

```sh
pip install maibot-plugin-sdk aiohttp pillow pytest
python -m pytest tests   # 本地假的 X 接口，不连外网、不要密钥
```
